# Demo video script (about 2:30)

Before recording: reset demo data (Rules tab), open the app in an Incognito window, keep the PayPal sandbox buyer login ready,
wake the server if it is hosted on a free plan. Free Gemini limits are low, so pause a few seconds between searches.

| Time | On screen | Say |
|---|---|---|
| 0:00 | App home | "AI agents can find deals, but who stops them from overspending? AgentPay lets AI shop while rules and PayPal keep you in control." |
| 0:20 | Type "Samsung phone under 15000" | "I ask in plain language. Gemini understands budget, brand and product type." |
| 0:40 | Agent activity + best deal | "The agent scanned about 14,000 listings. Gemini picked the best option, but only from deals that already passed every rule." |
| 1:00 | Rule checks | "Budget, rating, review count, per-order limit and daily cap are enforced on the server. The AI cannot override them." |
| 1:15 | Approve > review popup | "Nothing happens without my approval. Here is the full summary." |
| 1:30 | PayPal sandbox login > Complete Purchase | "Payment goes through PayPal. This is the sandbox, no real money." |
| 1:50 | Receipt: Authorized (on hold) | "PayPal authorizes the payment. Funds are held, not charged." |
| 2:00 | Click release payment | "After delivery I release it, and PayPal captures the payment." |
| 2:10 | Rules tab: set daily cap low, search again | "Now the guardrail: with a lower daily cap, the same purchase is blocked, and the reason is shown." |
| 2:25 | Orders tab | "Every step is logged. AgentPay: AI proposes, rules decide, PayPal executes." |
